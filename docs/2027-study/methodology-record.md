# Numerical methodology record (editorial review item 13)

Prepared 14 November 2026 for the First Edition, January 2027. One row per material figure. Evidence class: **P** published benchmark (named third-party source), **A** aggregated project data (Foreland Marine project archive, stated as more than 30 projects in ch01 and ch06), **W** practitioner working range (not counted project data), **M** illustrative model or worked example. Locations are chapter slugs on https://firstownersreference.com. "Check" records whether the arithmetic in the text was reproduced.
