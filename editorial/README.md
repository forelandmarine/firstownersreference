# Editorial material

Source material for The First Owner's Reference that sits outside the content pipeline. The published text itself lives in `content/*.json` and is edited through `/studio`.

## style-guide

`TFOR editorial style guide.md`, the voice and citation reference. Read it before drafting any copy for the publication.

The wider Foreland house style guide is separate and lives in iCloud at Foreland Group / Document Templates. That one governs client-facing Foreland writing; this one governs the publication.

## contributor-docs

Question sets sent to guest contributors and the answers that came back, one file per contributor per chapter. Filenames carry the contributor name and the chapter they answer for.

`firstownersreference-interview-questions.docx` is the master question bank. `firstownersreference-outreach.docx` is the approach letter. `TFOR Velema 2026-05-12` holds the numbered drafts sent to Hein Velema for approval.

Confirmed contributors and their status are tracked in `docs/interviewees.md`.

These are private correspondence with named third parties. `.docx`, `.pdf` and `.pages` are gitignored, so the folder is local only and does not reach GitHub.
